# 날씨 API 데이터 출처 및 이용 방법

본 프로젝트는 [공공데이터포털](https://www.data.go.kr/)의 **기상청_단기예보(구 동네예보) 조회서비스**를 사용합니다.

## 사용 API

1. **초단기실황조회** (`getUltraSrtNcst`)  
   - 실황 정보(기온, 강수, 풍속 등) 조회. 발표 시각은 매시 정시(HH00). 매시각 10분 이후 해당 시각 자료 이용 가능.

2. **초단기예보조회** (`getUltraSrtFcst`)  
   - 초단기예보(예보시점부터 6시간 이내). 발표 시각은 매시 30분(HH30). 동일하게 10분 이후 이용 가능.

## 필수 파라미터

- `serviceKey`: 공공데이터포털에서 발급한 인증키 (환경 변수 `WEATHER_API_SERVICE_KEY`에 설정)
- `base_date`: YYYYMMDD
- `base_time`: HHMM (실황 정시, 예보 00 또는 30)
- `nx`, `ny`: 기상청 격자 좌표 (기본값: 서울 60, 127)
- `dataType`: JSON

## 격자 좌표

- 기상청 API는 위·경도가 아닌 **격자 좌표(nx, ny)** 를 사용합니다.
- 본 프로젝트는 서울 기준 고정값(nx=60, ny=127)을 사용합니다. 다른 지역은 공공데이터포털 또는 기상청 안내에 따른 격자 변환 후 사용하면 됩니다.

## 환경 변수

- `.env.local` 및 Vercel에 `WEATHER_API_SERVICE_KEY`를 설정합니다.
- 인증키는 코드나 README에 직접 넣지 않고, 환경 변수로만 관리합니다.
