# 따릉이 대여소 데이터 업데이트 방법

본 프로젝트는 [서울 열린데이터광장](https://data.seoul.go.kr/dataList/OA-13252/F/1/datasetView.do)의 **공공자전거 따릉이 대여소 정보**를 파일 기반으로 사용합니다.

1. 위 링크에서 "파일내려받기" → 최신 Excel 또는 CSV 파일 다운로드
2. Excel인 경우 CSV로 저장하거나, 스크립트/도구로 JSON 배열 형태로 변환
3. 각 행 필드: 대여소명, 관리번호, 소재지주소, 위도, 경도, 거치대수 등 (열린데이터 광장 제공 컬럼명 유지)
4. 변환된 JSON을 `src/data/stations.json`에 덮어쓰기
5. 앱을 다시 빌드하거나 개발 서버를 재시작하면 대시보드에 반영됩니다.

갱신 주기는 반기(6개월)이므로 필요 시 위 절차를 반복하면 됩니다.
